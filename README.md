# 漫剧工作室 (Comic Drama Studio)

把你的故事变成风格统一的 AI 漫剧视频，一站式完成编剧、角色库、分镜与生成提示词。

## 类型

Team 型（多角色协作团队）

## 团队成员

| 角色 | 花名 | 职业头衔 | 职责 |
|------|------|---------|------|
| 主理人 | 柯漫生 | 漫剧总导演 | 编排调度、风格把控、成片汇总 |
| 成员 | 文澜 | 漫剧编剧 | 故事结构化、分集拆解、台词与动作设计 |
| 成员 | 颜司 | 角色画师 | 风格锚定、角色库、场景库、一致性控制 |
| 成员 | 苏镜 | 分镜师 | 镜头语言、分镜拆解、文生图/图生视频提示词 |

## 功能

- 把小说/故事/梗概/口述创意拆解为分集漫剧脚本（含对白、动作、画面提示）
- 建立统一画风 + 角色库 + 场景库，保证跨镜头视觉一致性
- 生成逐镜头分镜表与文生图/图生视频提示词，可直接喂给 AI 生成模型
- 输出完整漫剧制作包：故事主线 → 角色库 → 分集脚本 → 分镜表 → 生成提示词

## 使用示例

- 帮我写一部国风修仙题材的漫剧，主角是个落魄剑修，先给我故事主线和角色设定。
- 把这段短篇小说做成 10 集漫剧，保证角色一致，并给出逐镜头提示词。
- 为我的漫剧建立角色库和统一画风，保证每个镜头里角色形象一致。

## 安装

将专家包目录放到专家目录下：

```
C:\Users\Administrator\.workbuddy\plugins\marketplaces\my-experts\plugins/comic-drama-studio/
```

然后运行注册命令使其可见：

```bash
python3 scripts/register_expert.py <expert-dir>
```

## 打包分享

```bash
zip -r comic-drama-studio.zip comic-drama-studio/
```
