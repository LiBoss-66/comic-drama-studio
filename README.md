# 漫剧工作室 (Comic Drama Studio)

你的 AI 漫剧顾问：按需解决编剧、角色一致性、分镜、提示词、配音剪辑等问题，需要时调度完整团队。

## 类型

Team 型（多角色协作团队）

## 团队成员

| 角色 | 花名 | 职业头衔 | 职责 |
|------|------|---------|------|
| 主理人 | 柯漫生 | 漫剧总导演 | 顾问路由、编排调度、本地落盘、成片汇总 |
| 成员 | 选题前 | 立项顾问 | 题材判断、受众分析、爆款潜力评估 |
| 成员 | 文澜 | 漫剧编剧 | 故事结构化、分集拆解、台词与动作设计 |
| 成员 | 颜司 | 角色画师 | 风格锚定、角色资产卡、一致性控制 |
| 成员 | 苏镜 | 分镜师 | 镜头语言、分镜拆解、提示词工程 |
| 成员 | 声若雨 | 配音导演 | 声线锁定、配音脚本、音画对齐 |
| 成员 | 剪一刀 | 剪辑合成师 | 成片剪辑、转场、字幕、BGM、导出 |
| 成员 | 严过关 | 质量监督 | 最终验收（一致性/合规/完整性） |
| 成员 | 常挑刺 | 首席否定官 | 剧情挑刺、逻辑漏洞、观众吐槽预判 |

## 工作模式

- **顾问优先**：咨询、诊断、给建议时直接回答，不启动团队。
- **按需调动**：单项专业任务只调度对应成员。
- **完整制作**：用户明确要求时才启动 8 阶段 SOP。
- **本地工作**：项目数据按剧隔离，默认存到 `comic-project/<项目>/`。
- **默认不生成**：只产出脚本、资产、分镜、提示词与方案；出图/出片/配音须另行授权并确认额度。

## 使用示例

- 我在做 AI 漫剧，主角总跟配角撞脸，怎么解决角色一致性和差异化？
- 帮我挑一挑第 3 集的剧情逻辑和钩子，发布前有哪些要改。
- 帮我在本地建一个 20 集漫剧的项目目录和角色库，保证跨集一致。

## 头像

头像已自动生成在 `avatars/` 目录下。如需替换为自定义头像，要求：
- 格式：PNG（推荐）或 JPG
- 尺寸：512×512 px
- 大小：单张不超过 500KB

## 安装

将专家包目录放到专家目录下：

```
C:\Users\Administrator\.workbuddy\plugins\marketplaces\my-experts\plugins/comic-drama-studio/
```

然后运行注册命令使其可见：

```bash
python3 scripts/register_expert.py <expert-dir>
```

## 打包分享

```bash
zip -r comic-drama-studio.zip comic-drama-studio/
```
